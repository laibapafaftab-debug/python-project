## Projects

### Calculator
A simple calculator, built twice:
- **`calculator.py`** — a command-line version that takes two numbers and an operator, with input validation and divide-by-zero handling.
- **`index.html` / `style.css` / `script.js`** — the same logic rebuilt as a working browser app, with keyboard support.

[Live demo →] https://laibapafaftab-debug.github.io/python-project/

To run the command-line version:
```bash
python calculator.py
```
  
## What I learned

Building this project helped me practice:
- Writing clean, readable Python with proper error handling
- Structuring code into functions instead of one long script
- Rebuilding the same logic across two different environments (terminal and browser)
- Using Git and GitHub for version control
